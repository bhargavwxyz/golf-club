# Golf Club Dashboard

A Vite + React + TanStack Start dashboard application with Tailwind CSS and Radix UI components.

## What this project is

- A modern React app bootstrapped for server-side rendering and static build using `@tanstack/react-start`.
- Uses `@tanstack/react-router` for file-based route management.
- Includes a dashboard UI under `src/components/dashboard` with cards, charts, tables, and layout components.
- Uses `react-query` for data-fetching context and state management.

## Key technologies

- `vite` and TypeScript
- `react` / `react-dom`
- `@tanstack/react-router` and generated `src/routeTree.gen.ts`
- `@tanstack/react-start`
- `tailwindcss` and `@tailwindcss/vite`
- `@radix-ui/react-*` UI primitives
- `react-hook-form`, `zod`, `recharts`, `lucide-react`

## Project structure

- `src/`
  - `router.tsx` – creates the TanStack router with `routeTree` and `react-query` context.
  - `routeTree.gen.ts` – generated route tree mapping application routes.
  - `start.ts` – TanStack Start server bootstrap + error middleware.
  - `server.ts` – SSR server entrypoint used by Vite / Cloudflare plugin.
  - `styles.css` – global Tailwind CSS and app styling.
  - `components/dashboard/` – dashboard page layout and widgets:
    - `KpiCards.tsx`
    - `OfferFunnel.tsx`
    - `PendingOffersTable.tsx`
    - `RecentActivity.tsx`
    - `Sidebar.tsx`
    - `Topbar.tsx`
    - `ViewAllOffers.tsx`
  - `routes/` – page route definitions:
    - `__root.tsx` – root route shell, meta tags, error handling, and query provider.
    - `index.tsx` – main landing page route.

## Running the app

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Code quality

- `npm run lint` – run ESLint across the source.
- `npm run format` – apply Prettier formatting.

## Notes

- The `vite.config.ts` uses `@lovable.dev/vite-tanstack-config` to configure TanStack Start, Tailwind, React, and Cloudflare plugin integrations.
- `src/routeTree.gen.ts` is auto-generated by TanStack Router and should not be edited manually.

## Useful files

- `package.json` – scripts and dependencies.
- `tsconfig.json` – TypeScript config.
- `eslint.config.js` – lint rules.
- `vite.config.ts` – Vite and TanStack Start configuration.
